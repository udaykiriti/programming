commit message:

fix openrc-run PTY read handling and clean up small docs typos

  Prevent openrc-run from passing a failed PTY read result into
  write_prefix() as a size_t length. read() can return -1, and the old
  code forwarded that value directly, which could lead to an out-of-bounds
  buffer walk when processing prefixed service output. Read into a local
  ssize_t first, verify the result is positive, and only then call
  write_prefix(). Non-EINTR read failures are now reported explicitly.

  Also fix load_dep_env() to free the depsvcs list it allocates instead of
  freeing the unrelated services pointer. This avoids leaking the local
  dependency list and prevents cleanup of the wrong object.

  Finally, correct two documentation typos:
  - "enviroment" -> "environment" in rc.h.in
  - "retuning" -> "returning" in rc_stringlist.3
